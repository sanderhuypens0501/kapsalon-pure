# Pure, kapsalon Heverlee

Prototype van een website voor kapsalon Pure, Waversebaan 47, 3001 Heverlee.

- `index.html`, `style.css`, `script.js`, foto's in `img/`
- Live "Nu open"-status op basis van de openingsuren (Belgische tijd)
- Stalenring in de hero, voor/na-schuifregelaars, filter in het werk-grid

Foto's zijn voorbeeldbeelden van Unsplash. Vervang ze door foto's van het salon met dezelfde bestandsnamen.
Nog in te vullen: prijzen, teamnamen (te bevestigen), reviewcitaten met toestemming.
